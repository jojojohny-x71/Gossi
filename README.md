# Gossi

Offline-first multilingual earphone translator: cuts background noise, detects who is speaking
and in which language, translates everything into one language you understand, and speaks it in
your earbuds with a distinct voice per speaker — built on open-source models.

Status: planning. See [docs/PLAN.md](docs/PLAN.md) for the product spec, architecture, model
choices, and roadmap.
