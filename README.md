# Gossi

Offline Android earphone translator: removes background noise, detects who is speaking and
whether they speak Hindi, Tamil, Kannada or Malayalam, translates it into English, and speaks it
into your earbuds with a distinct voice per speaker. Runs fully on the phone using open-source
models (AI4Bharat IndicConformer + IndicTrans2, sherpa-onnx, Kokoro TTS).

Target setup: Nothing Phone (2) + Nothing Ear (a).

Status: planning. See [docs/PLAN.md](docs/PLAN.md) for the spec, architecture, model choices and roadmap.
